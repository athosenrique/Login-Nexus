# 🔐 Nexus — Interface de Login

Interface de login desenvolvida como parte dos meus estudos de desenvolvimento Front-End.

Este projeto teve como base um projeto apresentado em um curso de Desenvolvimento Web da Udemy. A partir da proposta original, fiz minhas próprias alterações e criei uma nova identidade visual chamada **Nexus**.

Este foi meu primeiro projeto focado em uma interface de login e uma oportunidade para colocar em prática os conhecimentos que venho adquirindo em HTML e CSS.

---

## 📌 Sobre o projeto

O Nexus é uma interface de login fictícia contendo:

- Campo para e-mail
- Campo para senha
- Opção de recuperação de senha
- Botão de login
- Login com Google
- Login com GitHub
- Opção para criar uma conta

O projeto possui apenas a parte visual. Os botões e links ainda não possuem funcionalidades reais de autenticação.

---

## 🎓 Origem e alterações

A ideia inicial foi baseada em um projeto apresentado durante um curso da **Udemy**.

A partir dele, fiz alterações para criar minha própria versão, incluindo:
